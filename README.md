# AMOGHA K. J — Animated Portfolio

React + Vite animated portfolio for Amogha K. J — Data Analyst | Software Developer.

## Run locally

```bash
npm install
npm run dev
```

## Production test

```bash
npm run build
npm run preview
```

## GitHub Pages

This project includes a GitHub Actions workflow that builds `dist/` and deploys that folder to GitHub Pages.

The Vite base path is configured for:

`/amogha-kj-portfolio/`
